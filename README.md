# Фаворит 2017 — тренування

Невеликий сайт для батьків команди ФК «Фаворит» 2017 р. н. з розкладом тренувань, таймером до наступного заняття, маршрутами та інформаційним блоком про повітряні тривоги.

## Розклад

- Понеділок: 19:15–20:30, Ліцей «Основа» (8 школа), Соборна, 3
- Середа: 19:15–20:30, Ліцей «Основа» (8 школа), Соборна, 3
- Четвер: 19:30–20:45, Гімназія «Перспектива» (4 школа), Київський шлях, 97

Графік не остаточний, але максимально наближений.
