# ФК «Фаворит» — клубна платформа

Повноцінна вебплатформа футбольного клубу для тренерів і батьків. FastAPI-бекенд зберігає дані в PostgreSQL, перевіряє ролі та права доступу, надсилає SMS-коди й запускає фонові нагадування. Якщо бекенд недоступний, статична сторінка автоматично переходить у локальний демо-режим.

## Можливості

- кабінети тренера й батьків;
- кілька команд із власними складами, чатами та розкладами;
- створення, редагування та видалення тренувань, матчів і турнірів;
- додавання, редагування та видалення гравців; номер батьків стає їхнім входом;
- опитування про присутність дитини з можливістю змінити відповідь;
- огляд відповідей для тренера та повторні нагадування;
- командні й особисті чати;
- PWA-режим, офлайн-кеш і справжні Web Push-сповіщення;
- інформація про повітряні тривоги в Бориспільському районі.

## Локальний запуск

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m uvicorn backend.main:app --reload
```

Відкрийте `http://127.0.0.1:8000`. За замовчуванням доступний демо-вхід. Для входу через форму використовуйте один із номерів у `backend/seed.py`; локальний код буде показано на екрані.

## Railway

1. Створіть Railway-проєкт із цього GitHub-репозиторію.
2. Додайте PostgreSQL — Railway передасть застосунку `DATABASE_URL`.
3. Додайте змінні з `.env.example`; обов’язково задайте довгий випадковий `JWT_SECRET`, а в `INITIAL_COACH_PHONE` вкажіть реальний номер тренера у форматі `+380XXXXXXXXX`.
4. Для кодів входу створіть Telegram-бота через [BotFather](https://t.me/BotFather), командою `/newbot`. Додайте `TELEGRAM_BOT_TOKEN`, `TELEGRAM_BOT_USERNAME` (без @), `TELEGRAM_WEBHOOK_SECRET` (випадкові 32+ латинські літери/цифри) та `PUBLIC_BASE_URL` (HTTPS-адреса сайту Railway). Webhook встановлюється при запуску. Токен не публікуйте; TurboSMS для входу більше не використовується.
5. Для push-сповіщень виконайте `python scripts/generate_vapid_keys.py` і додайте отримані `VAPID_PRIVATE_KEY` та `VAPID_PUBLIC_KEY` у Railway.
6. Для бойового режиму задайте `APP_ENV=production` та `ENABLE_DEMO=false`.

Railway автоматично знайде `Dockerfile` і запустить FastAPI. У налаштуваннях сервісу вкажіть healthcheck path `/api/health`.

## Перевірка
Перед першим входом відкрийте бота кнопкою «Підключити Telegram», натисніть Start і «Поділитися номером». Якщо номера ще немає в клубі, бот запропонує зареєструватися як тренер або батько. Потім поверніться на сайт та запросіть код. Прив’язки зберігаються в PostgreSQL; нові таблиці створюються автоматично.

`INITIAL_COACH_PHONE` застосовується лише до порожньої бази при `SEED_DEMO_DATA=true`. Зміна змінної не змінює тренера у вже заповненій базі.


```powershell
.\.venv\Scripts\python.exe -m pytest -q
```
