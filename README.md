# ФК «Фаворит» — клубна платформа

Вебплатформа футбольного клубу для адміністратора, тренерів і батьків. FastAPI зберігає дані в PostgreSQL, перевіряє права доступу, підтверджує вхід через Telegram і запускає нагадування. Якщо сервер недоступний, сторінка показує помилку з’єднання. Тестовий перегляд доступний лише коли його увімкнено на сервері.

## Можливості

- автоматична реєстрація та вхід через Telegram без введення кодів;
- кабінети адміністратора, тренера й батьків;
- адмінка: користувачі, ролі, блокування, команди, призначення тренерів, назва клубу й текст входу;
- керування складом, розкладом, турнірами й чатами всіх команд та видалення повідомлень адміністратором;
- кілька команд із власними складами, чатами та розкладами;
- створення, редагування та видалення тренувань, матчів і турнірів;
- додавання, редагування та видалення гравців; номер батьків стає їхнім входом;
- опитування про присутність дитини з можливістю змінити відповідь;
- огляд відповідей для тренера та повторні нагадування;
- командні й особисті чати;
- PWA-режим, офлайн-кеш і справжні Web Push-сповіщення;
- інформація про повітряні тривоги в Бориспільському районі.

## Локальний запуск

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m uvicorn backend.main:app --reload
```

Відкрийте `http://127.0.0.1:8000`. За замовчуванням доступний тестовий перегляд кабінетів батьків і тренера. Для справжнього входу налаштуйте Telegram-бота й HTTPS webhook. Змінні можна передати через середовище або `uvicorn backend.main:app --env-file .env`.

## Railway

1. Створіть Railway-проєкт із цього GitHub-репозиторію.
2. Додайте PostgreSQL — Railway передасть застосунку `DATABASE_URL`.
3. Додайте змінні з `.env.example`; обов’язково задайте довгий випадковий `JWT_SECRET`, а в `INITIAL_ADMIN_PHONE` вкажіть номер власника у форматі `+380XXXXXXXXX`. `INITIAL_ADMIN_NAME` задає його ім’я. Це працює також у заповненій базі, якщо в ній ще немає активного адміністратора.
4. Для входу без коду створіть Telegram-бота через [BotFather](https://t.me/BotFather), командою `/newbot`. Додайте `TELEGRAM_BOT_TOKEN`, `TELEGRAM_BOT_USERNAME` (без @), `TELEGRAM_WEBHOOK_SECRET` (випадкові 32+ латинські літери/цифри) та `PUBLIC_BASE_URL` (HTTPS-адреса сайту Railway). Webhook встановлюється при запуску. Токен не публікуйте.
5. Для push-сповіщень виконайте `python scripts/generate_vapid_keys.py` і додайте отримані `VAPID_PRIVATE_KEY` та `VAPID_PUBLIC_KEY` у Railway.
6. Для бойового режиму задайте `APP_ENV=production` та `ENABLE_DEMO=false`.

Railway автоматично знайде `Dockerfile` і запустить FastAPI. У налаштуваннях сервісу вкажіть healthcheck path `/api/health`.

## Перевірка
Натисніть «Підключити Telegram-бота» на сайті, потім Start і «Поділитися номером» у Telegram. Поверніться до тієї самої вкладки — сайт увійде автоматично. Незнайомий номер отримує профіль батьків без попереднього запрошення. Команда з’явиться, коли тренер додасть дитину з цим номером до складу.

Посилання містить випадковий одноразовий параметр `start`, діє 10 хвилин і прив’язується до Telegram-користувача. Окремий секрет залишається у `sessionStorage` вкладки; значення з посилання недостатньо для отримання токена входу. Сервер зберігає лише хеші секретів. Оновлення сторінки відновлює очікування, при втраті з’єднання сайт повторює запити. Бот приймає лише власний непересланий контакт. Звичайний `/start` не авторизує браузер.

### Адміністратор

1. Задайте `INITIAL_ADMIN_PHONE` у змінних Railway й перезапустіть сервіс. Таблиці `telegram_logins` і `club_settings` створяться автоматично; наявні дані залишаться.
2. Увійдіть через Telegram із цим номером. Відкрийте «Адміністрування» у меню; на телефоні — через кнопку профілю вгорі.
3. У «Користувачах» знайдіть людину за номером і змініть роль на «Тренер».
4. У «Командах» натисніть «Команда й тренер» та виберіть призначеного тренера. Новий тренер отримує доступ, попередній його втрачає.
5. Для керування подіями, гравцями, турнірами й чатами виберіть команду та відповідний розділ меню.

Блокування припиняє доступ до API навіть із раніше виданим токеном. Перед блокуванням тренера або переведенням у батьки передайте його команди іншому тренеру. Не можна забрати власний адміністративний доступ чи доступ останнього адміністратора. Видалення команди видаляє її склад, події, відповіді, турніри та чати після підтвердження в інтерфейсі; облікові записи користувачів зберігаються.

`INITIAL_ADMIN_PHONE` використовується лише за відсутності активного адміністратора. Після першого налаштування керуйте ролями через адмінку. Реєстрація завжди надає роль батьків: старі кнопки «Я тренер» більше не підвищують права. Раніше створені тренери зберігають свої ролі — перевірте їх у списку користувачів.

API-відповіді не кешуються браузером чи service worker. Старі OTP endpoints залишені для сумісності, новий інтерфейс ними не користується.

`INITIAL_COACH_PHONE` застосовується лише до порожньої бази при `SEED_DEMO_DATA=true`. Зміна змінної не змінює тренера у вже заповненій базі.

## Атрибуція

Тести перевіряють реєстрацію, прив’язку вкладки, повторне використання й прострочення посилань, порядок webhook-подій, контакти, права доступу, призначення тренерів і блокування. Telegram API у тестах замінено імітацією; після розгортання перевірте вхід справжнім ботом.

Протокол: [Telegram deep links](https://core.telegram.org/bots/features#deep-linking), [кнопка передачі контакту](https://core.telegram.org/bots/api#keyboardbutton).

Код взятий за основу з репозиторію [Posterminal/favorit-2016-training](https://github.com/Posterminal/favorit-2016-training).
