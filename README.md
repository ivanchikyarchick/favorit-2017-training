# ФК «Фаворит» — клубна платформа

Функціональний прототип платформи футбольного клубу для тренерів і батьків. Працює як адаптивний вебзастосунок і зберігає демодані на поточному пристрої.

## Можливості

- кабінети тренера й батьків;
- кілька команд із власними складами, чатами та розкладами;
- створення і редагування тренувань, матчів і турнірів;
- опитування про присутність дитини з можливістю змінити відповідь;
- огляд відповідей для тренера та повторні нагадування;
- командні й особисті чати;
- PWA-режим, офлайн-кеш і сповіщення браузера;
- інформація про повітряні тривоги в Бориспільському районі.

## Розклад

- Понеділок: 19:15–20:30, Ліцей «Основа» (8 школа), Соборна, 3
- Середа: 19:15–20:30, Ліцей «Основа» (8 школа), Соборна, 3
- Четвер: 19:30–20:45, Гімназія «Перспектива» (4 школа), Київський шлях, 97

Графік не остаточний, але максимально наближений.

## Демо-вхід

Для швидкого перегляду використовуйте кнопки кабінету батьків або тренера. У формі входу демо-код — `1111`.

Справжні SMS-коди, синхронізація між телефонами та гарантовані push-нагадування потребують окремого захищеного сервера й підключення SMS/push-провайдера.
